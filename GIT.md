## Найти коммиты в дифах которых есть текст поиска
Как выдернуть из истории гита все коммиты с подстрокой и саму строку с этой подстрокой
1. Шерстим гит на коммиты с дифами `git log -S"тнОбщийСервер.ПолучитьНастрой" -p > res.txt`
2. Преобразуем заголовок коммита в одну строку, чтобы потом прогрепать в студии: Поиск `commit (.*)\nAuthor:(.*)\nDate:(.*)\n\n(\s*)(.*)\n` замена `commit $1 Author:$2 Date:$3 "$5"\n`
3. Собственно грепаем: c:\soft\GIT\usr\bin\grep -E "commit|тнОбщийСервер.ПолучитьНастройки" res2.txt
   Грепаем, а не findstr, так как последний не умеет в юникод даже после chcp, а греп умеет.

## Частичное гит лего: включить в качестве сабмодуля только часть папок из соседнего репозитория

==**В Git нельзя клонировать сабмодуль частично** на уровне самого модуля, так как сабмодуль всегда указывает на конкретный коммит _всего_ удаленного репозитория==.

Однако вы можете решить эту задачу, скомбинировав **сабмодули (Git Submodules)** и **разреженное чекаут-клонирование (Git Sparse Checkout)**. Это позволит подключить репозиторий как сабмодуль, но физически скачать и отображать в рабочей директории только нужные папки.

Ниже приведена пошаговая инструкция, как это сделать.

Инструкция по настройке

Выполните следующие команды в корне вашего основного репозитория:

- **Добавьте сабмодуль без автоматического скачивания файлов:**
    
    bash
    
    ```
    git submodule add --no-checkout <URL_соседнего_репозитория> <путь_к_папке_сабмодуля>
    ```
    
    Use code with caution.
    
    _(Флаг `--no-checkout` зарегистрирует сабмодуль, но не будет скачивать его содержимое)._

- **Перейдите в директорию созданного сабмодуля:**
    
    bash
    
    ```
    cd <путь_к_папке_сабмодуля>
    ```
    
    Use code with caution.
    

- **Включите режим Sparse Checkout внутри сабмодуля:**
    
    bash
    
    ```
    git sparse-checkout init --cone
    ```
    
    Use code with caution.
    

- **Укажите, какие именно папки вам нужны:**
    
    bash
    
    ```
    git sparse-checkout set <путь/к/папке1> <путь/к/папке2>
    ```
    
    Use code with caution.
    
    _Указывайте пути относительно корня самого сабмодуля._

- **Выкачайте файлы выбранных папок:**
    
    bash
    
    ```
    git checkout
    ```
    
    Use code with caution.
    

Теперь в папке сабмодуля будут видны только те директории, которые вы указали в шаге 4. Для Git это останется полноценным сабмодулем, но место на диске будет экономиться.
